# PSY96 CBT Study Hub

A single-page study companion for Stanford Continuing Studies **PSY96: Managing Emotions with Skill**, an introduction to Cognitive Behavioral Therapy (CBT).

Open `index.html` in a browser. It has four tabs:

- **Study Guide**: visual notes for all five lectures plus a toolkit wrap-up
- **Flash Cards**: 46 cards, filterable by lecture, with "got it / still learning" tracking
- **Practice Quiz**: 30 multiple-choice questions with explanations and a per-lecture score
- **Journal**: guided prompts that apply the class tools to your own day

No build step, no dependencies. Everything is in one HTML file.

## Languages

The hub is available in three languages. Switch with the EN / 繁中 / ES links in the top red bar; your place in the page is kept when you switch.

| Language | File |
|---|---|
| English | `index.html` |
| Traditional Chinese (繁體中文) | `zh-hant/index.html` |
| Spanish (Español) | `es/index.html` |

Flash card progress, quiz scores and journal entries are shared across all three languages on the same device and browser. Translations were produced with AI assistance and have not yet been reviewed by native speakers.

## Privacy

Flash card progress, quiz scores and journal entries are stored only in your browser's `localStorage` on your device. Nothing is sent anywhere. Use the journal's **Export as Markdown** button to keep a copy.
